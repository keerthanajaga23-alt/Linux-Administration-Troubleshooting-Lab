# Linux Administration & Troubleshooting Lab

### Project Overview

This project demonstrates my practical learning in Linux system administration and troubleshooting using Ubuntu 24.04 LTS running on WSL2.

The lab covers essential Linux administration tasks, including user and group management, file permissions and ownership, process monitoring, service management, network troubleshooting, DNS configuration, SSH administration, and log analysis.

I also configured a local DNS zone using BIND9 and practised validating DNS configuration, testing DNS records, and investigating service and configuration issues.

### Objectives

* Practise essential Linux commands and system administration.
* Manage users, groups, file ownership, and permissions.
* Monitor processes, CPU, memory, and disk usage.
* Troubleshoot Linux services and network connectivity.
* Configure and test a local DNS zone using BIND9.
* Investigate errors using system and service logs.
* Develop a structured approach to technical troubleshooting.

### Environment

* **Operating system:** Ubuntu 24.04 LTS
* **Platform:** Windows Subsystem for Linux 2 (WSL2)
* **DNS server:** BIND9
* **Web server:** Nginx
* **Tools:** `systemctl`, `journalctl`, `ip`, `ss`, `ping`, `dig`, `nslookup`, `curl`

This project is a learning lab. The documentation will distinguish tested results from exercises that still require verification.
